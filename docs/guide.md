# 使用指南

## 首次使用

1. **协议自检**（推荐）：「系统设置 → 协议自检」，先不选账号跑一次匿名检查，再选上账号检查登录态、IM 和订单接口。字段覆盖率明显偏低说明平台接口有变化，先不要开启自动化。
2. **添加闲鱼账号**：「账号配置 → 扫码登录」，用闲鱼 App 扫码。也可以用浏览器扩展导出登录态后「导入 Cookie」。
   登录失效时点「重新登录」即可，**不要删除账号**（删除会清掉它的订单、会话和设置）。
3. **配置大模型**（要用 AI 功能时）：「模型配置」选择预设（DeepSeek / 通义 / Kimi / GLM / OpenRouter / Ollama 等）填入 API Key，「测试连接」通过后启用。多模态、对话、快速三个档位可以分别指定模型；模型不可用时 AI 相关功能自动降级为仅规则。
4. **配置通知渠道**：「通知设置」添加渠道（个人推荐 Server酱 / PushPlus 推送到微信），点「测试」确认能收到。
   **强烈建议配置**：账号掉线、发货失败、需要人工回复都靠它第一时间通知你。
5. **按需开启自动化**（默认全部关闭）：
   - 买家：「选品雷达」新建智能搜索，或直接说一句需求
   - 卖家：「商品管理」同步商品并设置底价与知识库 →「账号配置」打开自动回复（建议先用**建议模式**）→「自动发货」新建发货内容并关联商品后，再打开自动发货

## 选品雷达：写好判定标准

判定标准建议包含三部分：

```markdown
## 必须满足（一票否决）
- M1 芯片的 MacBook Air；电池健康 ≥ 85%；无拆修
## 加分项
- 个人自用、有原盒发票、同城可面交
## 危险信号
- 价格远低于市场、只收全款不走验货、引导加微信
```

- 关键信息缺失时 AI 给出“有条件推荐”，并生成可直接发给卖家的提问
- `rules` 是不花 token 的硬条件过滤：标题必须包含、排除词、地区、最低芝麻信用等
- 只按规则筛选不调用 AI：把判定方式设为 `rule`
- 被闲鱼限制时任务不会暂停，而是后台退避重试；连续被限制 5 次会通知你，可以在任务里改用账号搜索或换个网络

## AI 自动回复：开启、说明与资料

入口：「消息中心 → 自动回复」。买家消息先匹配关键词规则，没命中时才交给 AI。

- **开启**：在页面顶部给每个账号选择 AI 回复 `关闭 / 建议 / 自动发送`，默认关闭。「建议」会在收件箱里给出回复草稿，由你确认后发送；「自动发送」会同时打开自动回复总开关
- **给 AI 的说明**：用自己的话写店铺情况、说话语气、发货与售后规则（最多 2000 字），例如“学生党出闲置，周末不发货”“统一发中通，偏远地区不包邮”
- **资料文件**：上传说明书、FAQ、价目表等（txt / md / csv / pdf / docx，单个 ≤ 50MB），可设为所有账号通用或只给某个账号；AI 每次只取与买家问题相关的段落（最多约 1500 字），不会整份发送；可以随时停用或删除
- **试运行**：输入一句买家消息（可选咨询的商品），立刻看到会命中哪条规则或 AI 会怎么回，以及是否参考了资料；AI 未开启时也能先看效果
- 底价、站外联系方式、“保证正品”类承诺等安全规则始终优先，说明和资料里写了也不会突破

## AI 客服：议价策略

在「商品管理」为商品设置：

| 字段 | 示例 | 说明 |
|---|---|---|
| 底价 | 850 | **任何情况下都不会低于这个价格**，也不会出现在提示词里 |
| 最大轮次 | 3 | 超过后报最终价，不再让 |
| 让价阶梯 | 0.4 / 0.3 / 0.2 / 0.1 | 每轮让出（标价 − 底价）的比例 |
| 赠品 | 手机壳 | 用赠品代替降价 |
| 知识库 | 参数、瑕疵、使用说明 | AI 只依据这里和商品描述回答，不知道的会转人工 |

- 在「在线消息」里用「AI 回复试运行」查看某条消息会得到什么回复，不会真正发送
- 关键词规则先比适用范围（指定商品 > 指定账号 > 全部），范围相同才比优先级
- 「工作时段」只限制 AI，关键词回复和默认回复不受影响
- 你在 App 或网页亲自回复后，该会话暂停自动回复（默认 60 分钟）；期间买家再发消息会提醒你

## 自动发货

入口：「订单发货 → 自动发货」。① 新建发货内容 → ② 关联商品 → ③「账号配置 → 设置」打开自动发货。

| 发货方式 | 适用场景 | 说明 |
|---|---|---|
| 固定内容 | 教程、网盘链接 | 每单发送相同内容 |
| 卡密库存 | 激活码、兑换码 | 每行一张，导入自动去重，一卡一用，库存低于阈值告警 |
| 接口取货 | 对接自有系统 / 货源 | 配置 `url`、`method`、`headers`、`body`（支持变量）、`result_path` |

- 留言模板变量：`{content}`（也认 `{card}` / `{卡密}`）`{order_id}` `{buyer_name}` `{item_title}` `{spec}` `{quantity}`；没写 `{content}` 时内容会附在末尾
- 发货模式：先确认再发送 / 先发送再确认（默认）/ 只发送不确认
- 只有闲鱼订单接口确认“已付款”才会发货；发送结果拿不准时卡密保持锁定、订单转人工，提示你核对聊天

**电子资料想持续卖？**

- 在闲鱼 App 发布并设置库存（网页端对多数个人账号不开放库存），同步商品后关联发货内容，每卖一单自动发一份
- 或者关联时打开「卖完重新上架」：每次卖完自动发布一件同样的新商品，发货关联、底价、知识库一起转过去（适合每天几单；频繁重复发布可能被闲鱼限流）

## 实物订单发货

闲鱼网页版不支持填写运单号，实物订单需要在闲鱼 App 里发货。鱼塘管家负责提醒和省事：

- 实物订单（商品不是虚拟商品、也没有关联发货内容）付款后，推送「📦 实物订单待发货」，推送里不包含收货地址
- 「订单管理」里这类订单标为「待你发货」，点「去发货」：一键复制「姓名 电话 地址」，再用闲鱼 App 扫码直接打开这笔订单的发货页，选快递、填运单号
- 收货信息每次实时向闲鱼查询，不保存在本地，查看会写入操作审计
- 付款超过 24 小时还没发货会再提醒一次；在 App 发货后，订单会在下次同步（每 10 分钟）时自动变为「已发货」，也可以在弹窗里点「我已在 App 发货，刷新状态」

## 发布商品

- 上传图片，AI 生成标题、描述、成色、运费方式和客服知识库；售价按“你给的价格 > 同款行情 + 定价策略 > AI 估价”计算
- 「宝贝所在地」可以选城市或用当前位置，列出附近地点；发布后会记住
- 闲鱼要求身份认证时会弹出扫码窗口，用闲鱼 App 扫码完成刷脸后点「我已完成认证」自动重发

## 遇到风控 / 掉线

- **被平台限制**：系统已暂停该账号的写操作并通知你。打开通知或「账号配置」里的验证链接完成滑块 / 身份验证，回来点「我已完成验证」，保护期结束后自动恢复。**不要**频繁重启或反复重试
- **需重新登录**：「账号配置」点「重新登录」扫码，原有设置、商品关联和订单都会保留
- **消息连接断开**：系统会自动重连；超过 5 分钟没恢复会通知你，侧边栏和收件箱也会有提示
- **匿名搜索受限**（通常是当前网络 IP 被限流）：页面上的手动操作自动改用绑定的账号
- 不要用同一份登录态在别的浏览器或脚本里频繁打开闲鱼网页，闲鱼可能换发会话凭证，导致系统里的登录态失效

## MCP Server（只读）

让 Claude 等 AI 助手查询行情、选品结果、收件箱、订单，试运行客服回复，或把一句话需求转成智能搜索草稿。发送消息、发布、发货等写操作不开放。

1. 管理台调用 `POST /api/v1/auth/api-token` 生成令牌（与当前用户同权限）
2. 在 MCP 客户端中配置：

```json
{
  "mcpServers": {
    "xianyuhub": {
      "command": "uv",
      "args": ["--directory", "/path/to/XianyuHub/backend", "run", "--extra", "mcp", "python", "-m", "app.mcp_server"],
      "env": { "XYH_BASE_URL": "http://127.0.0.1:8000", "XYH_TOKEN": "<令牌>" }
    }
  }
}
```

## 浏览器扩展

`extension/` 是一个 Chrome / Edge 扩展，用来代替手动复制 Cookie。

**安装**：打开 `chrome://extensions`（Edge 为 `edge://extensions`）→ 打开「开发者模式」→「加载已解压的扩展程序」→ 选择 `extension` 目录。

**一键导入**：在同一个浏览器登录闲鱼网页版，然后在鱼塘管家「账号配置 → 导入 Cookie」（或账号的「重新登录 → 导入新 Cookie」）里点「从当前浏览器一键获取」。
每个管理台地址第一次读取时，扩展会弹框请你确认，避免同一台电脑上别的网页读取你的登录态。
管理台不是用 `localhost` / `127.0.0.1` 打开的，需要先在管理台页面点扩展图标 →「在当前网址启用一键导入」授权一次。

**自动续期**：一键导入时勾选「掉线时自动用这个浏览器的登录态恢复」后，扩展每 30 分钟、以及浏览器里重新登录闲鱼时检查一次：
账号在鱼塘管家里「需要重新登录」时，用浏览器里同一个闲鱼号的登录态自动恢复；账号正常时不做任何改动。
扩展里保存的是一个只能同步登录态的专用令牌（180 天有效），不能用来登录管理台。可以在扩展弹窗里随时停用。
