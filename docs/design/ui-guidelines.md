# 鱼塘管家前端 UI 规范

目标：美观、简约、易用、统一。改界面前先读这一页；新增页面优先复用下面的公共组件。

## 1. 设计令牌（`frontend/src/styles.css`）

组件样式里**不写死**颜色、字号、圆角，一律用 `var(--xh-*)`。Element Plus 的颜色变量已映射到同一套令牌。

| 类别 | 令牌 | 用途 |
|---|---|---|
| 品牌 | `--xh-primary` 鱼塘管家绿 `#1e9e6a`、`-hover`、`-soft`、`-border` | 主按钮、选中态、链接、焦点 |
| 中性 | `--xh-bg` `--xh-card` `--xh-fill` `--xh-fill-strong` `--xh-border` `--xh-border-strong` | 背景、卡片、浅底块、分割线 |
| 文字 | `--xh-text` 正文 · `--xh-text-2` 次要 · `--xh-muted` 辅助 · `--xh-disabled` | 文字只用这四档 |
| 语义 | `--xh-success` `--xh-warning`（文字用 `--xh-warning-text`） `--xh-danger` `--xh-info` | 只表示状态，且总是配文字 |
| 价格 | `--xh-price` `#ff4400` | 全站价格数字唯一颜色 |
| 字号 | `--xh-fs-xs` 12 · `sm` 13 · `md` 14 · `lg` 16 · `xl` 20 · `xxl` 28 | 不再使用 10.5 / 11.5 / 12.5 等零碎值 |
| 间距 | `--xh-space-1..5` = 4 / 8 / 12 / 16 / 24 | 组件内 8、区块间 12–16、页面间 16–24 |
| 圆角 | `--xh-radius-sm` 6 · `md` 10 · `lg` 16 · `pill` | 标签 6、卡片 10、大面板 16 |
| 阴影 | `--xh-shadow-1` 静止 · `--xh-shadow-2` 悬停 / 浮层 | 只有这两档 |

## 2. 原则

- **一种主色**：全站只用鱼塘管家绿。闲鱼相关的内容用闲鱼原生图标（包邮、验货宝等接口返回的图片），不把闲鱼黄当主题色。
- **不用表情符号**做标签或图标，统一用 `@element-plus/icons-vue`。
- **只展示真实数据**：没有数据就显示空状态或“—”，不写死看起来像统计结果的数字。
- **信息分层**：卡片上只放判断“要不要点进去”所需的信息；详情、分析、标记、次要操作放进抽屉或「⋯」菜单。
- **无意义的标签不显示**（如“样本不足”）。
- **操作可见**：不要只在鼠标悬停时出现，触屏上也要能点到。

## 3. 页面结构

```
顶栏（AppLayout：模块 · 页面名）
PageHeader：一行 = 标题 + 分段页签（可选） + 右侧操作按钮
FilterBar：一行；次要条件收进「更多筛选」
内容区
```

- 主按钮在操作区最右侧，每个区域最多一个主按钮。
- 空状态：一句说明 + 一个主操作，不放大段引导。

## 4. 公共组件

| 组件 | 用在哪里 |
|---|---|
| `RadarNav` | 选品雷达页头：一行标题 + 页签 + 操作 |
| `ItemCard` | 所有“闲鱼商品”卡片（智能搜索、实时搜货） |
| `ItemDrawer` | 所有商品详情：图片、描述、AI 判定、商品 / 商家分析、操作 |
| `ItemAnalysisPanel` / `BuyerRiskPanel` | 商品与商家分析、买家分析 |
