```mermaid
  B -->|"否"| C
  B2 --> C["保存任务<br/>cron / 实时间隔"]

  D --> E["扩词<br/>暗语词典 + 同义词"]

  G2 -->|"是"| N
  G2 -->|"否"| Z["结束"]

  M --> M1{"结论"}
  M1 -->|"RECOMMEND"| N["推送通知<br/>主图 / 价格 / 理由 / 手机链接"]
  M1 -->|"CONDITIONAL"| N2["进入看板，标黄<br/>生成待确认问题与咨询话术"]
  M1 -->|"REJECT"| O["进入看板（默认隐藏）"]
  N --> P["好货看板"]
  N2 --> P
  O --> P
  P --> Q["用户反馈<br/>收藏 / 不感兴趣 / 已买"]
  Q -->|"反馈信号"| R["偏好学习<br/>补充到 criteria 的用户偏好段"]
```

### 采集阶段的风控与降级

```mermaid
sequenceDiagram
  autonumber
  participant S as 调度器
  participant C as 采集 Worker
  participant G as 风控守卫
  participant P as 协议通道
  participant B as 浏览器通道
  participant N as 通知中心

  S->>C: 触发任务 T（关键词、筛选条件）
  C->>G: acquire(匿名池, search)
  G-->>C: 放行（令牌 + 抖动）
  C->>P: search_items(page=1..N)
  alt 成功
    P-->>C: 商品列表 DTO
  else 风控（USER_VALIDATE / RGV587）
    P-->>G: 上报风控信号
    G->>G: 匿名会话熔断，冷却 30 分钟
    C->>B: 降级：浏览器通道采集
    alt 浏览器也遇到滑块
      B-->>G: baxia 信号
      G->>N: 通知：任务 T 暂停，需要人工处理
      C-->>S: 任务失败（FailureGuard 计数 +1）
    else 成功
      B-->>C: 商品列表 DTO
    end
  end
  C->>C: 去重、初筛，候选商品进入详情队列
```

## 2. 卖家：消息处理与自动回复流程

```mermaid
sequenceDiagram
  autonumber
  participant X as 闲鱼 IM（LWP）
  participant GW as IM 网关
  participant ST as Redis Stream
  participant MP as 消息流水线
  participant RU as 规则引擎
  participant AG as Agent 编排
  participant PO as 议价策略
  participant GR as 输出护栏
  participant SD as 发送队列
  participant UI as 收件箱 / 通知

  X->>GW: syncPushPackage（base64 + msgpack）
  GW->>X: ACK（mid, sid）
  GW->>GW: 解码 → 识别类型（聊天 / 系统卡片 / 订单 / 输入中）
  GW->>ST: XADD im.inbound
  ST->>MP: 消费 chat.message.received
  MP->>UI: 实时推送到收件箱
  MP->>MP: 过滤：自己发出的？过期？系统卡片？重复？
  alt 是卖家本人发出的消息
    MP->>MP: 该会话进入人工接管（持久化，TTL 可配置）
  else 会话处于人工接管中
    MP->>MP: 只入库，不自动回复
  else 正常买家消息
    MP->>MP: 合并窗口（等待 3–8 秒，合并连续多条消息）
    MP->>RU: 关键词规则匹配（商品级 > 账号级 > 全局）
    alt 命中关键词
      RU-->>MP: 模板回复
    else 未命中，且 AI 已开启
      MP->>AG: 意图识别 + 上下文 + 商品知识库
      opt 意图 = 议价
        AG->>PO: 标价 / 底价 / 轮次 / 买家出价
        PO-->>AG: 本轮报价 offer、是否最终价
      end
      AG-->>MP: 候选回复
    else 都没有
      MP-->>MP: 默认回复（只回一次）或不回复
    end
    MP->>GR: 价格 ≥ 底价？禁用词？站外联系方式？
    alt 未通过
      GR-->>MP: 重写一次，仍不通过则改用模板回复或转人工
    end
    alt 模式 = 建议模式
      MP->>UI: 推送候选回复，等待人工一键发送
    else 模式 = 全自动
      MP->>SD: 入队（拟人延迟 + 限流）
      SD->>GW: XADD im.outbound
      GW->>X: /r/MessageSend/sendByReceiverScope
      SD->>UI: 记录已发送 + 审计
    end
  end
```

### 议价决策流程（代码层）

```mermaid
flowchart TD
  A["买家议价消息"] --> B["抽取买家出价 B<br/>正则 + LLM 兜底"]
  B --> C["加载 BargainPolicy<br/>标价 P / 底价 F / 最大轮次 N / 阶梯 r[]"]
  C --> D{"B ≥ P×0.98?"}
  D -->|"是"| D1["同意，引导拍下<br/>（可提示：拍下后改价）"]
  D -->|"否"| E{"轮次 n ≥ N?"}
  E -->|"是"| E1["报最终价 max(F, 上次报价)<br/>明确告知不能再少"]
  E -->|"否"| F["step = (P−F)×r[n]<br/>热度高则 step×0.5"]
  F --> G["offer = max(F, 上次报价−step)"]
  G --> H{"B ≥ offer?"}
  H -->|"是"| H1["按 B 成交"]
  H -->|"否"| H2["报 offer，可附带小赠品"]
  D1 & E1 & H1 & H2 --> I["LLM 组织话术<br/>只拿到 offer 等结构化结果"]
  I --> J{"护栏：回复中所有金额 ≥ F?"}
  J -->|"否"| K["拦截，改用模板"]
  J -->|"是"| L["发送，轮次 n+1 持久化"]
```

## 3. 卖家：订单与自动发货流程

```mermaid
sequenceDiagram
  autonumber
  participant X as 闲鱼
  participant GW as IM 网关
  participant OS as 订单服务
  participant RK as 发货前风控
  participant INV as 卡密库存
  participant DL as 发货执行器
  participant N as 通知 / 审计

  X->>GW: 系统消息「我已拍下，待付款」
  GW->>OS: order.event(orderId 来自 dxCard targetUrl)
  OS->>X: order.detail 补全（规格 / 金额 / 买家）
  OS->>OS: 幂等 upsert，状态 = 待付款
  X->>GW: 系统消息「我已付款，等待你发货」
  GW->>OS: order.event(paid)
  OS->>X: order.detail 二次校验（状态 = 待发货、金额一致）
  OS->>OS: 状态 → 已付款，发出 order.paid 事件
  OS->>RK: 预检查（信用阈值 / 重复下单 / 跨账号 / 黑名单 / 退款中）
  alt 命中风险
    RK->>N: 通知人工，订单标记为待人工处理
    opt 配置了自动关单
      RK->>X: close.by.seller
    end
  else 通过
    RK->>INV: 按 item_id + 规格分配卡券（行锁 / CAS 原子出库）
    alt 库存不足
      INV->>N: 缺货告警，订单进入补发队列
    else 分配成功（text / 卡密 / 图片 / API 取货）
      INV-->>DL: 发货内容
      DL->>DL: 套用发货模板（变量替换），处理延时发送
      alt 模式：先确认再发货
        DL->>X: consign.dummy（虚拟发货）
        DL->>GW: 发送卡密消息
      else 模式：先发货再确认
        DL->>GW: 发送卡密消息
        DL->>X: consign.dummy
      end
      alt 成功
        DL->>OS: 状态 → 已发货，写入 DeliveryRecord
        DL->>N: 发货成功日志 + 审计
      else 失败
        DL->>INV: 卡密回滚为 AVAILABLE（或标记为待确认）
        DL->>OS: 进入重试队列（指数退避，最多 4 次）
        DL->>N: 发货失败告警
      end
    end
  end
  X->>GW: 「交易成功 / 快给 ta 一个评价吧」
  GW->>OS: 状态 → 已完成，按配置自动评价 / 请求小红花
```

### 订单状态机

```mermaid
stateDiagram-v2
  [*] --> PENDING_PAY: 买家拍下
  PENDING_PAY --> PAID: 付款
  PENDING_PAY --> CLOSED: 超时或关单
  PAID --> RISK_HOLD: 发货前风控命中
  RISK_HOLD --> PAID: 人工放行
  RISK_HOLD --> CLOSED: 人工或自动关单
  PAID --> DELIVERING: 分配卡券
  DELIVERING --> DELIVERED: 发送成功并确认发货
  DELIVERING --> DELIVER_FAILED: 发送或确认失败
  DELIVER_FAILED --> DELIVERING: 重试或补发
  DELIVER_FAILED --> MANUAL: 超过重试次数
  DELIVERED --> RECEIVED: 买家确认收货
  DELIVERED --> REFUNDING: 申请退款
  RECEIVED --> RATED: 完成评价
  RECEIVED --> REFUNDING: 售后
  REFUNDING --> REFUNDED: 退款完成
  REFUNDING --> RECEIVED: 退款撤销
  RATED --> [*]
  REFUNDED --> [*]
  CLOSED --> [*]
```

## 4. 卖家：AI 辅助发布商品流程

```mermaid
flowchart TD
  A["卖家上传商品图片<br/>+ 一句话说明（可选）"] --> B["多模态 AI 识别<br/>品类 / 品牌 / 型号 / 成色 / 瑕疵"]

  G -->|"定时发布"| G2["加入发布队列<br/>指定时间"]

  G2 --> H
  H --> I["上传图片<br/>stream-upload"]
  I --> J["获取默认地址<br/>local.poi.get"]
  J --> K["发布<br/>idleitem.publish"]
  K -->|"成功"| L["回写 item_id → MY_ITEM<br/>绑定议价策略 / 卡券 / 知识库"]
```

## 5. 账号登录、续期与风控熔断

### 5.1 账号状态机

```mermaid
stateDiagram-v2
  [*] --> NEED_LOGIN: 新增账号
  NEED_LOGIN --> ACTIVE: 扫码成功或导入 Cookie 校验通过
  ACTIVE --> ACTIVE: 定时刷新 _m_h5_tk 和 accessToken
  ACTIVE --> RENEWING: SESSION_EXPIRED
  RENEWING --> ACTIVE: hasLogin.do 或浏览器续期成功
  RENEWING --> NEED_LOGIN: 续期失败，通知重新扫码
  ACTIVE --> CIRCUIT_OPEN: 风控信号（USER_VALIDATE、RGV587、punish）
  CIRCUIT_OPEN --> WAIT_HUMAN: 推送验证链接或远程浏览器
  WAIT_HUMAN --> COOLDOWN: 人工验证完成（拿到 x5sec）
  CIRCUIT_OPEN --> COOLDOWN: 冷却计时（指数退避）
  COOLDOWN --> ACTIVE: 冷却结束且探活成功
  COOLDOWN --> CIRCUIT_OPEN: 探活仍然触发风控
  ACTIVE --> DISABLED: 用户停用
  DISABLED --> NEED_LOGIN: 重新启用
```

### 5.2 扫码登录时序

```mermaid
sequenceDiagram
  autonumber
  participant U as 用户
  participant W as Web 管理台
  participant A as 账号服务
  participant P as passport.goofish.com
  participant H as h5api（mtop）

  U->>W: 点击“添加闲鱼账号”
  W->>A: POST /accounts/qr
  A->>P: mini_login.htm（获取 XSRF-TOKEN）
  A->>P: qrcode/generate.do
  P-->>A: codeContent, t, ck
  A-->>W: 二维码（SSE 推送状态）
  U->>U: 闲鱼 App 扫码并确认
  loop 每 2 秒轮询
    A->>P: qrcode/query.do
    P-->>A: NEW / SCANNED / CONFIRMED / EXPIRED
  end
  alt CONFIRMED
    A->>P: login_token/login.do
    P-->>A: Set-Cookie（unb, cookie2, sgcookie ...）
    A->>H: 刷新 _m_h5_tk（loginuser.get）
    A->>A: 加密存储 Cookie，绑定代理，状态改为 ACTIVE
    A-->>W: 登录成功（昵称、头像）
  else 需要人脸或核身（iv 验证）
    A-->>W: 返回核身链接，或打开远程浏览器由人工完成
  end
```
